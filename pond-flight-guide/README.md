# Reading the Pond Flight

A field guide to reading the five map products from the August 19, 2026 multispectral drone flight — orthomosaic, NDVI, NDRE, VARI, and surface model — explained with the flight's own imagery and numbers.

**Read it here:** https://lukasmadams11.github.io/pond-flight-guide/

Built from the delivered Pix4Dfields GeoTIFFs (Sentera 5-band multispectral, 3.3 cm/px, 30.1 acres). The page is a single self-contained HTML file.
